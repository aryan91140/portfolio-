# 🎬 Aryan — 3D Video Editor & Visual Storyteller Portfolio

> **"Behind every frame, there's a story."**  
> An ultra-modern, interactive 3D portfolio crafted for Video Editors, Filmmakers, and Visual Storytellers. Built with React, Vite, Three.js WebGL, Tailwind CSS, and Web Audio API.

---

## 🌟 Key Features

- **🌌 Interactive 3D WebGL Background (Three.js):** 3D film strip ribbons, floating lens aperture rings, anamorphic bokeh particles, and scroll-linked 3D camera travel.
- **🎯 Cinematic Reticle Cursor & HUD:** Camera crosshairs with dynamic context labels (`PLAY`, `DRAG`, `WATCH`, `DIRECTOR`) and live 24fps timecode counter.
- **🔊 Web Audio API Sound Synthesizer:** Built-in UI audio engine with subtle whooshes, clicks, and shutter snaps.
- **🎞️ Curated Video Gallery:** Categorized sections for **Cinematics**, **Visual Edit / VFX**, **Viral Short-Form Reels**, and **Commercial Ads**.
- **🎚️ Draggable "Before & After" Color Grade Slider:** Compare flat RAW S-Log3 footage with final ACEScc + Kodak Hollywood LUT grade.
- **🎛️ Interactive Multi-Track NLE Timeline:** Premiere Pro & After Effects workflow simulator where visitors can inspect individual clip decisions.
- **🛠️ Tools Suite Showcase:** Detailed 3D cards for **Adobe Premiere Pro**, **Adobe After Effects**, and **CapCut Pro**.
- **🎉 Interactive Inquiries & Confetti:** Project scope selector with confetti celebration upon inquiry submission.

## 🚀 Quick Start Guide

### 1. Clone or Download the Repository
```bash
git clone https://github.com/YOUR_USERNAME/aryan-video-editor-portfolio.git
cd aryan-video-editor-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the portfolio.

### 4. Build for Production
```bash
npm run build
```

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **3D Graphics:** Three.js (WebGL)
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations & Effects:** Framer Motion + Canvas Confetti
- **Audio:** Web Audio API (zero external assets needed)
